# Local artifacts and optional qualification

npm publication uses the single manual `main` workflow in
[docs/npm-publishing.md](../../docs/npm-publishing.md). The controller, ceremony, recovery, and
trusted-publisher inspection gates were retired in #269. None of the optional tools below is a
prerequisite for that workflow, and ordinary contributors run `pnpm check`.

## Caller inventory (#240)

| Tools | Current callers and reason to retain |
| --- | --- |
| `build-local-release.mjs`, `inspect-local-release.mjs` | Packaging tests and manual platform qualification build/inspect tarballs, contracts, skills, licenses, and provenance locally |
| `qualify-local-release.mjs`, `index-platform-evidence.mjs` | Manual `local-platform-qualification.yml`; distinct installed-artifact compatibility checks for maintained OS/architecture rows |
| `index-host-evidence.mjs --policy deferred` | Manual `local-host-support.yml`; historical empty support-index tooling, separate from npm publication |
| `bind-host-evidence.mjs`, `qualify-host-evidence.mjs` | Disabled `local-host-evidence-capture.yml` and its adversarial evidence-validation tests |
| `prepare-host-qualification.mjs`, `hash-host-evidence.mjs`, `rehearse-host-qualification.mjs` | Optional operator kits generated by `host-evidence.mjs`, plus kit/evidence tests |
| `index-host-evidence.mjs` without deferred policy | Optional host-evidence indexing implementation retained for #188; not in the ordinary contributor or npm path |
| `generate-local-documentation.mjs`, `generate-vendored-skills-manifest.mjs` | Current reference/archive generation and pinned skill-provenance updates |

The eleven `local:release:*` root commands are aliases for these scripts. They have real consumers
or an explicitly deferred host-support purpose; reducing their count alone would not remove work.
Their security and packaging tests remain in `pnpm test`. Those tests create temporary local
artifacts and mock host/service boundaries; they do not dispatch workflows or certify a real host.

`local-host-evidence-capture.yml` remains disabled manually (verified during #240). Do not enable or
dispatch it for the deferred 1.0 policy. No workflow state, secrets, protections, tags, or published
artifacts are changed by this cleanup. Historical [ADRs](../../docs/adr/) and
[release evidence](../../docs/release-evidence/) remain available, but do not define extra npm gates.

For a local candidate only:

```sh
pnpm local:release:build --output /absolute/path/to/empty-candidate-directory
pnpm local:release:inspect --candidate /absolute/path/to/empty-candidate-directory
```

The candidate builder requires a clean committed checkout so provenance describes exact source.
The packaging test intentionally exercises that path in a temporary checkout of HEAD; final
validation should follow a local commit. These artifacts are not published by the build or inspect
commands. See [reference owners and regeneration](../../docs/reference-generation.md) for docs.
